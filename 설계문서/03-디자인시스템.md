# 디자인 시스템

> 전부 `style.css` 한 파일에 있다(빌드 도구 없음). 라이트/다크는 사용자가 앱 안에서 고르는 토글이 아니라
> **OS/브라우저의 `prefers-color-scheme`를 그대로 따른다** — 수동 전환 UI는 없음.

## 1. 색상 토큰

| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `--bg` | `#f6f7f9` | `#14161a` | 페이지 배경 |
| `--card` | `#ffffff` | `#1e2126` | 카드·모달 배경 |
| `--card-2` | `#eef0f3` | `#262a31` | 카드 위 서브 배경(뱃지 등) |
| `--text` | `#1c1e21` | `#e6e8eb` | 본문 텍스트 |
| `--muted` | `#6b7280` | `#9aa1ab` | 보조 텍스트 |
| `--border` | `#e5e7eb` | `#2e333b` | 테두리 |
| `--accent` | `#2f6b4f` | `#6cc099` | 브랜드 그린 — "마이웨이트", 버튼·강조 |
| `--accent-soft` | `#e2efe9` | `#1d2a23` | accent의 옅은 배경 (뱃지·패널) |
| `--love` | `#b5486f` | `#e08aa8` | 브랜드 로즈 — "마이러브" |
| `--social` | `#b0542f` | `#e08a63` | 응원/루틴/질문 계열 글 종류 뱃지 |
| `--up` / `--down` | `#dc2626` / `#16a34a` | `#f87171` / `#4ade80` | 증가/감소(스파크라인·목표 비교) |
| `--error` | `#b91c1c` | `#f87171` | 폼 에러 |
| `--rank-1~5` | 회색→진보라 계열 | 밝은 톤 대응 | 등급 뱃지(흑연~다이아몬드) |

**색 고를 때 원칙**: `--up`(빨강)이 "체중 증가"를 나타내는데, 일반적인 "증가=좋음(초록)" 관례와 반대로 간다 —
다이어트 맥락에서 증가가 부정적 신호이기 때문. 새 지표를 추가할 때 이 관례를 유지할지 먼저 확인할 것.

## 2. 타이포그래피

| 용도 | 폰트 | 비고 |
|---|---|---|
| 본문/UI 전체 | 시스템 폰트 스택 (`system-ui, -apple-system, "Segoe UI", Roboto, "Apple SD Gothic Neo", "Noto Sans KR"`) | 커스텀 폰트 로드 없음 — 빠름 |
| 랜딩 히어로 워드마크 (`.wordmark`) | Google Fonts **Gowun Batang** (700) | 브랜드 이름에만 사용, `index.html`에서만 로드 |
| 워드마크 영문 서브텍스트 (`.en-name`) | Google Fonts **Fraunces** (italic 500) | 위와 동일 |

기본 본문 크기 `15px`, 줄간격 `1.55`. `h1 1.4rem / h2 1.15rem / h3 1rem`.

## 3. 브랜드 자산

- **워드마크**: "마이웨이트"(accent 그린) + 쉼표(muted) + "마이러브"(love 로즈) — 이름 자체를 두 색으로 나눠 서비스 성격을 표현.
  랜딩 히어로(`index.html`)에만 크게 노출, 다른 화면엔 반복 안 함("문 앞에서만" 원칙).
- **엠블럼**: "결의 하트" — 보석처럼 깎인 하트 모양, `favicon.svg`. 브라우저 탭 아이콘 + 소개 페이지 하단 서명(`.brand-sig`)에 사용.
- **홈 화면 아이콘**: 엠블럼과 별개로, 좌우 절반 2색(그린/로즈) + 중앙 흰색 "M" 글자. `scripts/make_icons.py`로 생성(Pillow, 폰트 파일 없이 좌표로 직접 그림).
  모서리는 이미지에 미리 둥글리지 않고 정사각형 풀블리드로 둠 — OS가 자체적으로 마스킹하기 때문(먼저 둥글이면 안드로이드에서 흰 테두리로 비침).

## 4. 컴포넌트 인벤토리 (`app.js`)

| 컴포넌트 | 역할 |
|---|---|
| `Avatar` | 아바타 이미지 또는 이니셜 원형 |
| `RankBadge` | 등급 색상 텍스트 뱃지 (흑연~다이아몬드) |
| `KindBadge` | 글 종류 뱃지 (기록/루틴/소회/질문) |
| `EncourageBtn` | 응원 토글 버튼 |
| `ImageUpload` | 이미지 업로드 + 캔버스 리사이즈 미리보기 |
| `Lightbox` | 이미지 확대 보기 |
| `Sparkline` | 인라인 SVG 추세 그래프 (프로필) |
| `NoticeCard` | 관리자 공지 카드 |
| `Modal` | 바텀시트형 모달 셸 (몸무게/글/챌린지 작성에 재사용) |
| `PostCard` / `PostView` | 피드 카드 / 글 상세 |
| `Spinner` / `ErrorBox` | 로딩·에러 공통 상태 |

## 5. 레이아웃 규칙

- 앱 셸 최대폭 `620px`, 랜딩 최대폭 `560px` — 데스크톱에서도 모바일 폭으로 가운데 정렬 (반응형 그리드 아님, 모바일 우선 고정폭)
- 하단 탭바 5개(피드·챌린지·＋·알림·나) + 가운데 플로팅 ＋ 버튼(액션시트)
- 카드형 UI 전반: `border-radius: 12~16px`, `border: 1px solid var(--border)`, 그림자 없음(플랫 디자인)
